# Character sprite assets

Playable characters in the Brovary Universe branch:

- `pbot` — P-BOT mascot, 6-frame run cycle + jump.
- `brovary-hero` — Brovary Hero, 6-frame run cycle + crouch/jump/fall.
- `vitalii` — Vitalii, 5-frame run cycle + crouch/jump/fall.

Source generations use chroma-key green. Production sheets are converted to transparent WebP and cropped at runtime using frame rectangles embedded in `apps/web/public/app.js`.
